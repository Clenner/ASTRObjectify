# ASTRObjectify
## How to install on Windows
1. Go into the Installers folder
2. Double-click WINDOWS.bat
## How to install on Linux
1. Go into the Installers folder
2. Run a terminal there
3. In the terminal, run ```chmod +x ./LINUX.sh```
4. Lastly, run ```./LINUX.sh```
## How to run the program after installation
#### WARNING: MANY FEATURES MAY NOT FUNCTION IF THE INSTALLATION DOESNT WORK
###### Double-click Run-AOY.bat, or run ```py interface.py``` from a terminal

=====ABOUT=====

Welcome to ASTRObjectify!

Here's the quick rundown:

Create New Mod; Creates a brand new Workspace for you to start modmaking.

Edit Existing Mod; Allows you to select a Workspace that already exists, and edit it.

Import Mod; Allows you to import a .pak file into the Workspace Editor incase you lost yours, or want to edit someone else's.

About; isn't that self explanatory? I mean– you literally clicked on it to get here...

Exit; Simply just stops the program.

The most recent mod edited will be in the bottom right corner, that's called Quick-Edit!

When you export a mod, it will be in \ASTRObjectify-main\Workspaces\NAME\versions\
